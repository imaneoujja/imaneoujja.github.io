# Imane Oujja - Portfolio Website

A creative and interactive portfolio website showcasing my journey as a Master's student in Computer Science at EPFL, specialized in AI & Data Science.

## Features

- 🎨 **EPFL Color Scheme**: Red, white, and pink theme inspired by EPFL
- ✨ **Interactive Animations**: Smooth scroll-triggered animations using Framer Motion
- 📱 **Fully Responsive**: Works seamlessly on all devices
- 🚀 **Modern Stack**: Built with Next.js 14, TypeScript, and Tailwind CSS
- 📖 **Storytelling Design**: Creative layout that tells my professional story

## Sections

- **Hero**: Animated introduction with typing effect
- **Introduction**: Personal story and background
- **Projects**: Featured projects including NLP, ML, and Data Science work
- **Experience**: Work experience timeline with achievements
- **Education**: Academic journey with university logos
- **Programs & Initiatives**: WAVE Fellowship, JPMorgan Chase, EPFelles
- **Skills**: Programming languages, technologies, and concepts
- **Contact**: Get in touch section with social links

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install
# or
pnpm install

# Run development server
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Build for Production

```bash
npm run build
# or
pnpm build
```

## Deployment

The site is configured for static export and can be deployed to:
- GitHub Pages
- Vercel
- Netlify
- Any static hosting service

- **Next.js 14**: React framework
